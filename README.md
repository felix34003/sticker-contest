## Features
- **Modern Charcoal & Warm Gold Palette:** Sleek, high-contrast, uncluttered design.
- **Top 3 Podium:** Highlights 1st, 2nd, and 3rd place designs with large artwork and real-time vote tallies.
- **Visual Voting Modal:** Mobile-friendly visual sticker selector with Hawk ID username-only input (`@hawk.illinoistech.edu`).
- **Google Sheets Backend:** 100% free serverless architecture using Google Apps Script Web App.
